# 🏠 AGS-home-safety

यह प्रोजेक्ट **Home Safety (घर की सुरक्षा)** को बेहतर बनाने और उसे ऑटोमेट करने के लिए बनाया गया है। इसमें सुरक्षा से जुड़े विभिन्न सेंसर्स और फीचर्स का इस्तेमाल किया गया है।

## ✨ मुख्य विशेषताएं (Features)
* **Real-time Monitoring:** घर की सुरक्षा की चौबीसों घंटे निगरानी।
* **Alert System:** किसी भी अप्रत्याशित गतिविधि या खतरे पर तुरंत अलर्ट।
* **Smart Access Control:** मुख्य दरवाजे के लिए सुरक्षित डिजिटल एक्सेस।

## 🛠️ आवश्यक उपकरण (Hardware Required)
* **Microcontroller:** Arduino Uno / ESP32 / ESP8266
* **Sensors:** 
  * PIR मोशन सेंसर (गति पहचानने के लिए)
  * MQ-2 गैस/धुआं सेंसर (आग या गैस लीक के लिए)
  * Ultrasonic सेंसर (दूरी मापने के लिए)
* **Buzzer / LED:** अलार्म नोटिफिकेशन के लिए
